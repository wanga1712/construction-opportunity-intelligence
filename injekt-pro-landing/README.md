# Лендинг injekt-pro.ru — ООО «Кардинал Инжиниринг»

Премиальный инженерный одностраничный сайт направления:
- гидроизоляция подземных паркингов;
- инъектирование трещин в бетоне;
- ремонт деформационных швов;
- герметизация технологических вводов коммуникаций;
- гидроизоляция подвалов МКД и технических помещений.

---

## 1. Структура проекта

```text
/injekt-pro-landing
  index.html        # Главная страница (HTML5, OpenGraph, микроразметка)
  styles.css        # Стили (темная премиальная тема, графит, золото, адаптив)
  script.js         # Интерактив (маска телефона, модальные окна, dropzone, сохранение заявок)
  server.py         # Локальный HTTP-сервер со сбором лидов в leads.json
  /assets
    /images         # Фотографии (чистый подземный паркинг, технические узлы)
    /icons          # SVG иконки
  README.md         # Инструкция по эксплуатации и редактированию
```

---

## 2. Локальный запуск на Сервере 13

### Способ А: Встроенный Python сервер с логированием лидов (Рекомендуется)
```bash
cd /opt/injekt-pro-landing
python3 server.py
```
Сайт доступен по адресу: `http://localhost:8080` или `http://10.8.0.13:8080` (VPN) / `http://192.168.1.80:8080` (LAN).

### Способ Б: Стандартный Python http.server
```bash
cd /opt/injekt-pro-landing
python3 -m http.server 8080
```

### Способ В: Фоновый сервис systemd (на сервере 13)
При необходимости постоянной работы можно использовать `systemd` или `tmux`/`screen`.

## 6. Как собираются заявки

1. На стороне клиента заявки сохраняются в `localStorage` браузера (`injekt_pro_leads`).
2. При отправке формы идет `POST /api/lead` на сервер `server.py`, который автоматически сохраняет данные в локальный файл `leads.json`.
3. Показывается сообщение об успешной фиксации:
   > «Заявка зафиксирована. Мы свяжемся с вами для уточнения объекта.»
