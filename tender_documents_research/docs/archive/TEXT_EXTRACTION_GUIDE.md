## 🚀 Внедрение

### Этап 1: Тестирование (БЕЗОПАСНО)

```bash
cd /opt/tender_documents_research

# Запустить тесты
python3 test_text_extraction.py

# Протестировать на реальных данных
python3 enhanced_matcher.py
```

### Этап 2: Интеграция с существующим matcher

**Вариант A: Минимальные изменения (рекомендуется)**

Добавить в `document_processor/matcher.py` после получения совпадений:

```python
# В конце метода process_text(), перед return matches
if os.getenv("ENABLE_SMART_EXTRACTION", "0") == "1":
    try:
        from smart_text_extractor import improve_existing_matches
        matches = improve_existing_matches(matches)
    except Exception as e:
        self.logger.error(f"Smart extraction error: {e}")
        # Продолжаем с оригинальными совпадениями
```

**Вариант B: Полная замена (для продвинутых пользователей)**

Заменить `KeywordMatcher` на `EnhancedKeywordMatcher` в `task_pipeline.py`:

```python
# Было:
from document_processor.matcher import KeywordMatcher

# Стало:
from enhanced_matcher import EnhancedKeywordMatcher as KeywordMatcher
```

### Этап 3: Настройка переменных окружения

Добавить в systemd сервис:

```bash
sudo systemctl edit tendermonitor-document-research.service
```

```ini
[Service]
Environment=ENABLE_SMART_EXTRACTION=1
Environment=MAX_FRAGMENT_LENGTH=200
Environment=SAVE_ORIGINAL_LINES=0
```

### Этап 4: Перезапуск и мониторинг

```bash
sudo systemctl daemon-reload
sudo systemctl restart tendermonitor-document-research.service

# Мониторинг
journalctl -u tendermonitor-document-research.service -f
tm-status
```

## 🔧 Настройки

| Переменная | Умолчание | Описание |
|---|---|---|
| `ENABLE_SMART_EXTRACTION` | `0` | Включить умное извлечение текста |
| `MAX_FRAGMENT_LENGTH` | `200` | Максимальная длина фрагмента |
| `SAVE_ORIGINAL_LINES` | `0` | Сохранять оригинальные строки для отладки |

## 📋 Что улучшается

### ✅ Решаемые проблемы:

1. **Слишком длинные строки** — обрезаются до 200 символов с сохранением смысла
2. **Нечитаемый текст из Excel/PDF** — очищается от артефактов форматирования
3. **Отсутствие контекста** — добавляется контекст до и после совпадения
4. **Дублирование информации** — убираются повторы

### ✅ Новые возможности:

1. **Подсветка ключевых слов** — `**слово**` в тексте
2. **Уровень уверенности** — высокая/хорошая/средняя/низкая
3. **Метод извлечения** — exact_match/word_match/fuzzy_match
4. **Экономия места в БД** — до 88% экономии
