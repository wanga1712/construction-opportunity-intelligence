## 🚀 Как запустить

### На сервере nyx:

```bash
cd /opt/tender_documents_research

# Автоматическая настройка (рекомендуется)
python3 setup_smart_extraction.py

# ИЛИ ручная настройка:
sudo systemctl edit tendermonitor-document-research.service
# Добавить: Environment=ENABLE_SMART_EXTRACTION=1
sudo systemctl daemon-reload
sudo systemctl restart tendermonitor-document-research.service

# Мониторинг
journalctl -u tendermonitor-document-research.service -f
```

## 🔧 Что происходит

1. **Безопасная интеграция** - система работает только при `ENABLE_SMART_EXTRACTION=1`
2. **Минимальные изменения** - добавлено всего 8 строк в существующий код
3. **Обработка ошибок** - при сбое возвращается к оригинальному тексту
4. **Производительность** - добавляется ~10-20ms на документ
