# WIP folder

Все WIP, которые ставятся на выполнение, живут здесь — по одному файлу на WIP:

```
docs/wip/WIP_<NAME>_V<n>.md
```

Правила:

1. Созданный WIP получает адрес (путь в репозитории) и отдаётся исполнителю.
2. После выполнения тот же файл дополняется секцией `## RESULT` — исходное
   задание не переписывается.
3. Сравнение «что просили / что сделано» делается по этому файлу.

Формат результата:

```
## RESULT (YYYY-MM-DD)
STATUS: DONE | PARTIAL | BLOCKED
EVIDENCE: команды/запросы и их вывод
ACCEPTANCE: пункт = факт
DEVIATIONS: что не совпало и почему
FOLLOW-UP: что осталось
```
